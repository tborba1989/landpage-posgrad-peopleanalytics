Perguntas frequentes

Tire suas dúvidas.

Preciso ter experiência em programação para começar? +

Não. O programa foi desenhado para partir do zero absoluto. Se você sabe usar Excel, você consegue acompanhar desde a primeira aula. A progressão é gradual e cada ferramenta é introduzida com instalação passo a passo antes de qualquer linha de código.

O certificado é reconhecido pelo MEC? +

Sim. A certificação é emitida pela Anhanguera, instituição integrante do grupo Cogna Educação — o maior grupo educacional do mundo. O curso segue rigorosamente a Resolução CNE/CES n. 1/2018, que regula a oferta de pós-graduação lato sensu no Brasil.

Quanto tempo tenho para concluir o curso? +

O curso tem estrutura flexível com entrada intermitente. A carga horária total é de 360 horas, distribuídas em 9 disciplinas de 40 horas cada. O ritmo é definido pelo aluno dentro do prazo de integralização estabelecido pela instituição.

Os projetos práticos são individuais ou em grupo? +

Todos os 6 projetos práticos são individuais. O objetivo é que cada aluno construa um portfólio próprio, aplicável à realidade da sua organização. Os projetos são cumulativos — o banco de dados da D04 alimenta o pipeline da D05, que alimenta o dashboard da D06, e assim por diante.

Qual a diferença entre este programa e outros cursos de People Analytics do mercado? +

Esta é a única pós-graduação lato sensu do Brasil 100% dedicada a People Analytics com certificação MEC. Os demais programas disponíveis são cursos livres (sem certificação acadêmica reconhecida), pós-graduações genéricas de RH (sem conteúdo técnico) ou cursos de dados genéricos (sem contexto de gestão de pessoas). Este programa resolve os três problemas simultaneamente.

Quais ferramentas precisarei instalar? +

PostgreSQL, DBeaver, Anaconda (Python + Jupyter Notebook) e Power BI Desktop — todas gratuitas. O curso inclui guia de instalação passo a passo para Windows, Mac e Linux. Nenhum software pago é exigido durante o programa.
